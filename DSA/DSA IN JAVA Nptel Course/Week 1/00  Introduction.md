Every measurable entity has attributes and these attributes contain data. like a employee can have attributes like age, salary and gender. Data helps us to gather information about the entity and find solutions to our problems. This is why preservation of data is very important. As the digital world grows the data also keeps growing and to keep it useable and informative for us we structure it and maintain it. 

Data structure:- A defined data which can be handled by a program. 
Primitive data:- simple data which can be processed by a programming language is known as primitive data. Like boolean, char and string. 

Primitive data is not enough to work on every problem. many times we need to use complex data which require complex handling for being processed. This is where we need DSA

Types of data structures:-  There are basic data structures which we already use like arrays, tree, linked-list, set etc. Then comes advance data structures which are made with these data structures. 

In basic data structure we have 2 types of data structure:-
1)- Linear data structure:- Data structures which linearly store data in one dimension form. 
eg:- array, linkedlist, tack and queue 
2)- Non linear data structure:- Data structures which store data in a non linaer and multidimensional way.
eg:- tree, graph, table and set.
